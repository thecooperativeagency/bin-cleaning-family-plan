02 How the DIY machine works

Four systems

  1. Tip / hold — invert or cradle the can over a grate
  2. Wash — gas pressure washer + turbo/wand (spin head later)
  3. Fresh water — 275-gal IBC → filter → washer
  4. Grey water — catch runoff → dirty IBC → RV dump

Stop workflow

  1. Roll can to trailer
  2. Pre-spray degreaser / Fabuloso-type, short dwell
  3. Tip onto grate / cradle
  4. Blast interior, wand lips/edges
  5. Deodorize (OdoBan-type) on handles + interior
  6. Return can; pump hopper → grey when full
  7. Dump grey legally end of route / as needed

Recommended route workflow (chemicals)

Standard residential can

  1. Pull debris (grabber) into bag
  2. Pump-spray Simple Green or Fabuloso interior + lid
  3. Dwell 1–3 minutes while you stage next can
  4. Pressure rinse (turbo interior, wand lips/edges)
  5. Light OdoBan mist interior + wipe handles
  6. Return can; photo if needed

Filthy / first-time / summer stink

  1. Debris out
  2. Stronger degreaser spot (Krud Kutter / Zep / HF degreaser cut)
  3. Longer dwell
  4. Rinse thoroughly
  5. OdoBan disinfect dilution
  6. Enzyme mist if still smells after visual clean
  7. Optional controlled bleach step only if trained — then rinse policy clear

Dilution & application notes

  • Pump sprayer is king on bins — you control wetness and dwell. Downstream injectors dilute hard (~1:10–1:20) and waste product on vertical plastic.
  • Always follow the label SDS for disinfection contact times (OdoBan, etc.).
  • Mix only what you’ll use in a few days for RTU bottles; concentrates live sealed.
  • Hot water (later upgrade) multiplies every chemical — cold water needs dwell.
  • Grey water will contain chem residue — dump only at approved sites; don’t invent storm-drain chemistry.

Hard rules (non-negotiable)

Never

  • Mix bleach + ammonia (Fabuloso has variants — read label)
  • Mix bleach + acids / vinegar “boosts”
  • Store bleach in a hot closed cab all week
  • Spray random strong chem on customer landscaping
  • Use open food containers as chem jugs
  • Claim EPA kill rates you didn’t follow dilution/time for

Always

  • Gloves + glasses when mixing
  • Labeled bottles only
  • SDS packet in dry box
  • Spill kit: absorbent + bag + water rinse plan
  • Rinse customer driveway splash marks
  • Keep kids/pets away during dwell
